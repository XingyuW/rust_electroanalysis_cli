`codex/mhi-v1-a1-lineage-evidence-adapters`.  It deliberately excludes the
Phase B mechanism assessor and Phase C health diagnosis.

Current raw and standalone producers construct a deterministic `Known` identity
from their owned scientific payload and authoritative scope where available;
derived calibration and mechanism producers record direct known dependencies.
When a producer cannot establish a required source, it emits explicit
schema-versioned `LegacyUnknown`. Historical deserialization and reserialization
never promote a legacy artifact into `Known`.

## A1-FR-001 optional-artifact consumption matrix

| Artifact | When loaded | When scientifically consumed | Dependency persisted when |
|---|---|---|---|
| transient | `estimate run --transient-results` | A valid selected transient parameter supplies the resolved tau used by the state model | The resolved tau source is transient; role `Initialization` |
| calibration model | Required `--calibration-model` | Stored calibration equations are used for every estimate | The known model lineage is available; role `Calibration` |
| calibration analysis | Optional `--calibration-results` | Selected calibration residual variance is the resolved measurement variance source | The covariance resolver selects `CalibrationArtifact`; role `Calibration` |
| signal | Optional `--signal-results` | Selected signal robust/stable-window variance is the resolved measurement variance source | The covariance resolver selects `SignalArtifact`; role `AuxiliaryInput` |
| EIS | Optional `--eis-fit` | Supplied artifact is retained for the existing observability/validation-input contract | Only when that approved validation-input contract is active; role `ValidationInput` |
| mechanism | Optional `--mechanism-results` | Not consumed by estimation science | Never |
| health baseline | Optional `--health-baseline` | Not consumed by estimation science | Never |
| health assessment | Optional `--health-assessment` | Not consumed by estimation science | Never |
| model-analysis/health outputs | Not estimator inputs in A1 | Not consumed by estimation science | Never |

## A1-FR-002 evidence status

The permanent tests above are production-path evidence, not aliases to broad
helpers. The A1-FR-001 runner matrix executes `estimate run`; the two transient
bundle tests execute public artifact reread and the production bundle entrypoint;
the EIS tests execute producer construction, serialization, public reread,
adapter normalization, and bundle covariance assembly. No test claims Phase B
mechanism scoring or Phase C health scoring.
