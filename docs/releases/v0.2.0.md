# rust_electroanalysis_cli v0.2.0

Release date: 2026-09-24

## Purpose

v0.2.0 is the first release intended for routine use of the current electrochemical
analysis CLI while the more stringent Phase F REAL governance program remains
unfinished.

This release can be used for research data analysis. It does **not** assert Phase F
REAL authority, G3 approval, or physical-validation approval.

## Analysis capabilities

The release includes the current workflows for:

- EIS fitting and equivalent-circuit search;
- potentiometric transient fitting;
- calibration extraction, fitting, validation, and prediction;
- EIS/transient mechanism-timescale comparison and trends;
- signal characterization, comparison, and residual analysis;
- sensor-health baseline, assessment, and trend workflows;
- EKF/UKF state estimation and validation;
- plotting and machine-readable JSON/CSV/TXT outputs;
- reduced-order ISM model validation, simulation, decomposition, and reporting.

Physical input is handled through the pinned `electrodata-io` provider revision.

## Reproducibility

The crate version is embedded in produced provenance as

2. input-file hashes;
3. configuration files;
4. the command line used;

## Scientific claim boundary

A fitted timescale, circuit parameter, latent state, health feature, or reduced-order
ISM component is analysis evidence. The software does not automatically convert those
outputs into a physical-mechanism diagnosis. High-fidelity transport/mechanism claims
require separate physical evidence and validation.

## Installation

From this release/tag:

```bash
cargo build --locked --release
./target/release/rust_electroanalysis_cli --help
```

or install from the checked-out source:

```bash
cargo install --path . --locked
rust_electroanalysis_cli --help
```
